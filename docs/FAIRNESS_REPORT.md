# Fairness Report — pd_lgbm_v2 (synthetic population)

**Real-data fairness is in [`VALIDATION_REPORT.md`](VALIDATION_REPORT.md)** (UCI Taiwan and German Credit, real SEX / AGE / EDUCATION / MARRIAGE attributes, all models at the same approval rate). This page covers the synthetic Turkish population only.

In v1 the protected attributes were generated independently of default, so AIR was good *by construction*. The generator now builds realistic proxy correlations — tenure grows with age (employment months ≤ working life since 18), metropolitan provinces earn more, and a gender pay gap — so the numbers below show how proxies move AIR even though the attributes are never model inputs.

Generated by `scripts/fairness_report.py` on the time-based test set (application months 21–24) of the seeded synthetic population (16,803 applications). Approval = calibrated PD ≤ automatic-approval cut-off (8%).

Overall approval rate: **54.8%**

The synthetic proxies are deliberately mild, so synthetic AIR stays high; the substantive finding is on real data: on German Credit the champion fails the four-fifths rule for age band. No less discriminatory alternative stays within the allowed AUC loss on both out-of-fold and hold-out data (the LightGBM family would raise the age-band AIR to 0.780, still below 0.8, but loses 0.020 AUC out-of-fold), so the finding is open and goes to the model risk committee (see the LDA tables in `VALIDATION_REPORT.md`).

## Interpretation

- AIR values below 0.8 raise an alert in `/api/v1/governance/fairness` and on the management dashboard.
- Disparities in the synthetic data stem from the proxies built into the generator (tenure ↔ age, income ↔ province and gender); the protected attributes themselves are never model inputs.
- All alternatives are compared at the same approval rate, so an AIR change is a fairness change and not a volume change. Group-specific thresholds use the protected attribute at decision time and are shown only to size the trade-off (legally problematic).
- The model risk committee decides whether a less discriminatory alternative should replace the champion.
- Live monitoring recomputes AIR on real decisions using attributes captured with explicit consent.
